Parallax

Stellar Community Fund #46 · RFP: Web and API Analytics

Usage you can check, not usage you are told.

Parallax is a shared analytics service for projects building on Stellar. It measures websites and APIs the same way for everyone, without cookies, without storing IP addresses, and with defenses against inflated numbers.

Three things to try

Each takes under a minute. Keep the operator console open in another tab and watch it change.

Counted

Visit a measured site

Open the demo site and click around. Your browser earns a short-lived token, then sends one event per page. No cookie is set; check the network tab.

Rejected

Try to forge a visit

The website id is public, like any analytics id. Use it to add traffic from a terminal:

curl -s -X POST {{INGEST}}/e \
  -H 'Origin: {{DEMO_ORIGIN}}' \
  -d '{"type":"event","payload":{"website":"{{DEMO_WEBSITE}}","url":"/"}}'
{"code":"missing-token", ...}

The attempt is refused, and it shows up in the console as a rejected event with its reason.

Normalized

Call an API with a Stellar address

The demo API reports to Parallax through OpenTelemetry. Call it with any account:

curl -s {{API_DEMO}}/accounts/GA5ZSEJYB37JRC5AVCIA5MOP4RHTM335X2KGX3IHOJAPP5RE34K4KZVN/payments

About 15 seconds later the console lists the route below. The address was never stored, and neither was the trace.

GET /accounts/{account}/payments

What is stored, and what never is

A measurement service is only as trustworthy as its restraint.

Stored

  • Page views, visitors, referrers, session duration, bounce rate, country, device and browser.
  • API request counts, status codes and latency per normalized route.
  • A traffic class for every event: confident, low confidence or automated. Rejections are counted too.

Never stored

  • Full IP addresses. They are truncated inside the gateway, before anything else sees them.
  • Cookies, or any identifier that follows a visitor from one project to another.
  • Traces, spans and logs. The collector derives the numbers and drops the rest.
  • Raw API paths. Stellar accounts, contracts, hashes and IDs become placeholders.
GET /accounts/GA5ZSEJYB37JRC5AVCIA5MOP4RHTM335X2KGX3IHOJAPP5RE34K4KZVN/payments  →  GET /accounts/{account}/payments
